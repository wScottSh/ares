DESIGN FREEDOM
Pick how to reach scenes deterministically: scripted input from cold boot, a generated save file (MM uses flash), or ares save states regenerated by script from cold boot. Whatever you pick must be regenerable by one script from the ROM alone, because timing changes in later units invalidate states.

- Two consecutive runs byte-identical.
- Total wall time for the bench reported (budget 2 min for 600 frames per run on the final model; report today's number).
- Run the #23 runtime confirmation recipe and report found vs expected values.
