## Deviations

1. **Engine change in `rdp_core.c`:** hazard primitives are published before the drain on both return paths. This keeps serialization free of mutation. It is pixel-neutral on MM, and repeater64 passes 21/21.
2. **Engine fix:** XBUS command words are byteswapped (a T9 adaptation bug). The engine README touch-site table has the current line numbers.
3. **Hidden plane on reset:** it is kept across a reset. Before, the Vulkan reload refilled it on every power.
4. **Files the plan did not name:** the n64-run script steps, `state-roundtrip.sh`, `determinism.sh`, and the RDP command tracer, which moved to `rdp/debugger.cpp` and walks the range itself.
5. **`cimg`/`zimg`:** these are the engine's 25-bit masked addresses, not the old 26-bit parse. Values are identical on MM.
6. **Left in place:** the LICENSE MoltenVK block and the `cmake/macos/helpers.cmake` MoltenVK lines. The macOS bundle may still ship MoltenVK, and those lines are not N64 wiring.
7. **Round trip scope:** the round trip runs in-process. `cpu.profile.cpuCycles` is not in the save state (T2 follow-up), so a load into a fresh process is not proven here.
