## 6. Deleted hack and engine bug fix (from code)
- rdp_fill_rect_stale_read (cen64's fitted hack, D = min(3L-2, 25)) removed with m_rect_stale and its serialization. Replaced by window timing; behavior now emergent. Net: 32 px cases lost (see 3). This is a disclosed behavior change that the plan asked for (rdpstat:1prim stale-read cases; ADR Decision 3 line 136), not smuggled.
- zhb fix (rdp_core.c:5910): `sw->zhb = zb_address` (byte address used as halfword-plane index) -> `zb_address >> 1`. The hidden plane is one byte per halfword indexed by (address>>1) (color path uses fb_address>>1), and hardware stores dz in the Z halfword's own ninth bits, so the old index was a port bug and also lay outside any per-image window. Required by T13, correct. It may change fb_hash on Z-using fields; the worker did not trace the 70/600 power-on field hash differences (not traced by me either).
- mem_misses = 0 on MM, all four timed runs (stderr `mem_misses=0`).

## 8. Wall time (reproduced) and profile
Copied runners, interleaved base/head x4, load 1.07-1.31: base 21.171, 21.104, 21.118, 21.098 s (median 21.11); head 28.513, 28.428, 28.541, 28.523 (median 28.52). +35.1%. Budget 120 s: fine for T13, but T14-T17 stack on it.
perf record (-F 499, 600 fields): samples base 9803, head 12610 (+2807). Where the delta is: RDP actor scheduling/polling, not pixels. RDP::readiness +474 (44 -> 518), Timeline::advance +342, rdp_render_span_peek +312, RI::run +252, RDP::dispatchable +207, RDP::step +147, Port::eligible +142, poly_manager_peek +136, writeBack/pipeline/prefetch/post +253; that is about 2,300 samples (~80%). Pixel work is a small part: render_ms 2705 -> 3882 (+1.2 s; window lookups plus per-span run), 345,484 calls both. So the cost is mostly avoidable implementation cost: readiness() and dispatchable() are called on every timeline advance and each re-peeks the poly pool (span_peek memsets and fills a struct) and scans port queues. Caching the peek/dispatchable result until the pipeline/queue changes should recover most of it. Modeling cost proper (extra RI grants, chunking at half boundaries) is the Timeline::advance/RI::run part, ~600 samples.
