## What changed
- engine/rdp_core.c: the 1-/2-cycle rectangle hazard hold now collects Set Combine, Set Other Modes and Set Tile as well as Set Env Color. Each write lands at its own stage of the n64brew Pipeline table "Effect of unsynced attribute changes" (rdp-command-timing.md s.3.7): D(stage) = min(3L-2, depth + offset(stage) - offset(combiner)). Set Env Color keeps cen64's +1 for the 2-cycle cycle-1 case. A Set Other Modes write lands per field group. Offset-0 stages never reach the previous primitive. Writes are records (rdp_haz_write), stable-sorted by pixel. Re-renders chain one object per landing pixel. Env re-renders now carry env alpha too.
- depth = rdp.pipeline-depth, passed through rdp_render_init (engine.cpp) in place of the literal 25.
- timed.cpp dispatch: a primitive's spans enter the pipeline after its own setup, not after the writes its window collected.
- New ROM rdpstat-unsynced and check rdpstat:unsynced-combiner (the table's combiner row: last 24 cycles in 1-cycle, 22 in 2-cycle). New behaviors row rdp.attribute-stage (map, wiki). rdp.pipeline-depth reference is rewritten. checks.tsv nosync-1cycle now says 20 references. rcp.py gained the ENVIRONMENT combiner input.

## DEVIATIONS
1. Files: the change is in engine/rdp_core.c, rdp_core.h, rdp.c, rdp.h and engine.cpp, not only timed.cpp. The snapshot and the hazard hold live in the engine. timed.cpp changes only in dispatch().
2. 65 vs 20 references (see above).
3. Inference: the table's offsets are relative stage positions, and the captures pin the combiner at rdp.pipeline-depth. In 1-cycle they agree (table 24 = D - 1). In 2-cycle the table's combiner is 22, but the env captures need 25. The captures win for env; the other stages use the 2-cycle column relative to its combiner row. The 3L-2 bound applies to every stage. The rows note this.
4. dither_alpha_en goes with alpha_compare_en. Set Convert is not collected (its handler drains the span queue). Cycle type, atomic, detail/sharpen and bi_lerp are not in the table and stay per primitive.
5. Commit trailer uses the session attribution (Claude Opus 5.5).

## FOLLOW-UPS
- Only the combiner row and env color are checked. The texture, blender, z_mode and dither rows are built from the wiki alone and need console captures.
- Triangles are out of scope (cen64 fit rectangles only).
- The hold sees only buffered commands. A write that reaches the FIFO after the rect dispatches does not reach the rect (pre-existing).
- The re-render scheme overdraws the tail. With IM_RD blending or Z update a pixel blends twice or fails its Z compare (pre-existing for env; new stages inherit it). Rendering disjoint ranges would fix it.
- repeater64 FillTri/UndefShade ports and rdpstat:1prim have no published source (as briefed).
