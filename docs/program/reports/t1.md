## What changed
- Deleted cpu/recompiler{,-fpu,-ipu}.cpp and rsp/recompiler.cpp (and their structs in cpu.hpp/rsp.hpp).
- accuracy.hpp: CPU/RSP Interpreter/Recompiler switches and JitInterleaving gone. jitClockTarget, forceSynchronize (13 call sites in ai/rdp/rsp/si/vi io), interruptPoll (only called forceSynchronize) gone.

- "Recompiler" core option removed; desktop-ui N64, 64DD, Aleck64 (arcade.cpp) no longer set it. forceInterpreter setting stays (ps1, sh2 use it).
- n64-run --cpu removed; run-nemu64.sh --cpu removed (results dir now results/nemu64/); README updated.
- sljit stays: ares/CMakeLists.txt links it to the whole ares lib and ares.hpp includes it; sh2 (32X/Saturn) and ps1 use it. N64 no longer references sljit, bump_allocator, or nall/recompiler.

## Interpreter code that only made sense alongside the recompiler (left, report only)
- countClock / pendingCount / flushCount / effectiveCount (lazy COUNT): built for batched sync. With per-instruction sync it is still semantically live (MFC0 COUNT mid-instruction, COMPARE/COUNT writes), so kept. TimedCp0 (T7c) replaces it.
- CPU::queueInsert is now a one-line forward to queue.insert (its jitClockTarget clamp is gone). T5 replaces the queue.
- CPU::OpInfo flags and decoder*Info: no reader until T7a.
- Thread::clock subtract-at-sync in CPU::synchronize and per-device main() catch-up still run every instruction; that is the interpreter's own model, T4/T5 replace it.
