## Config
- Build: tools/n64-timing/build.sh, RelWithDebInfo, g++ -O2 -g -DNDEBUG (no clang++ on unicron). This is the harness config, so it is the one I report. A Release (-O3) build was not measured.
- Host unicron: AMD RYZEN AI MAX+ 395, 16C/32T, amd-pstate-epp, governor powersave on all 32 CPUs, EPP balance_performance, 625 MHz to 5187.5 MHz. Effective clock on the runner's core was 3.47 to 3.52 GHz (perf cycles / wall).
- Method: runner cp'd to a fresh file (pref 26). Each scene ran alone and serially with the mmbench-generated script (`n64-run MM --script S --stats F --frames 3000 --wall-seconds 600`, the same args mmbench.py uses) under `perf stat -e task-clock,cycles,instructions`. Order: power-on, then 7 scenes, repeated 3 times. Every run's stats.tsv was byte-identical to the reference mmbench run's, and every stop line was script-stop (frame-limit for power-on).
- Wall = the runner's wall_s for the whole cold-boot run (boot + route + window). That is an upper bound on the 600-field window.
