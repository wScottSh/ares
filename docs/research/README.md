| [scheduler-granularity.md](scheduler-granularity.md) (+ `scheduler-granularity/`) | [#9](https://github.com/wScottSh/ares/issues/9) | MM South Clock Town is the load case (RSP runs during 53% of CPU instructions vs 7% at boot; interpreter 14.05 s per 600 fields).
