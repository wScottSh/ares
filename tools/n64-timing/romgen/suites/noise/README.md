# noise

The noise suite ports [Thar0/RDP-Noise](https://github.com/Thar0/RDP-Noise) at commit `e7f6c7f` (`rdp_noise.c`) to one romgen ROM. The ROM draws the RDP's combiner NOISE input into a 1016x1 RGBA32 rectangle and dumps it. The check is `noise:rect-1016` in `tools/n64-timing/checks.tsv`.

| ROM | Source | Record |
|---|---|---|
| `noise-rect-1016.z64` | `rdp_noise.c` | `@snap noise-rect-1016 4064 <fnv>` and the hex dump of the 1016 pixels |

The draw follows `rdp_noise.c`. It uses 1-cycle mode with blending and dithering off and the combiner `(NOISE - 0) x PRIM_LOD_FRAC + 0` with `PRIM_LOD_FRAC = 255`, and draws one fill rectangle over the surface.

## Commands

Run these from the repository root.

```sh
python tools/n64-timing/romgen/build.py --suite noise --out $N64_TIMING_HOME/roms
N64_RUN=<path to n64-run> tools/n64-timing/romgen/suites/noise/run.sh
```

- `run.sh` runs the ROM and decodes the rectangle with `decode.py`, which is Thar0's `fb2data.py` clamp inverse. It then runs `n64-timing-noise rect`, from `tools/n64-timing/tests/noise-lfsr.cpp`.
- The checker finds the RDP clock whose `a` outputs start the run. Every pixel's `a`, `b` and `c` must then be the LFSRs at its own clock, one clock per pixel. It prints that clock and how many clocks later dataset A, the console capture, shows the same sequence. The clocks differ because this ROM reaches its rectangle sooner after power-on than Thar0's libdragon program. The pixel-to-clock offset (`rdp.noise-pixel-offset`) is unmeasured, so the check does not assert the absolute clock.
- Output goes to `$N64_TIMING_HOME/results/noise/`: `stdout.txt`, `stderr.txt`, `bits.txt` and `summary.txt`.

## Port notes

- `rdpq_attach` and `rdpq_set_mode_standard` become explicit commands: SET_COLOR_IMAGE, a scissor over the whole surface, and SET_OTHER_MODES for 1-cycle with RGB and alpha dither disabled and a zero render mode.
- The surface is at the fixed address `0x00500000`. The CPU clears it before the draw.
- The dump uses the snapper suite's `snap_emit` routine.
